# Kebijakan Keamanan

Laporkan kerentanan secara privat lewat **Security → Report a vulnerability** di repositori ini
(GitHub Private Vulnerability Reporting), bukan lewat issue publik. Kami berusaha menanggapi dalam 7 hari.

Catatan: aplikasi ini statis, tidak punya server atau akun pengguna. Data pengguna (preferensi,
riwayat, penanda baca) hanya disimpan di peramban masing-masing (localStorage/IndexedDB).
